# Reconstructed history

This repository was initialized from supplied project files without original
Git history or milestone tags. The original supplied snapshot is preserved
locally under refs/backup/supplied-snapshot, dated at snapshot creation time.

Author and committer dates from October 2 through October 30, 2026 use
America/Toronto time (UTC-04:00) and are reconstructed illustrative dates,
not evidence of when the work was actually performed. The configured Git
identity identifies the person performing reconstruction, not necessarily
the original author.

Complete existing files were grouped into plausible development milestones.
Intermediate commits are not claimed to be historical or independently
runnable versions. Original project bytes were preserved; only this
disclosure was added. Local runtime artifacts and the reconstruction helper
are excluded from version control.
